Sampling-Aliasing-Demonstrator

A MATLAB-based demonstration of Sampling and Aliasing in Digital Signal Processing.

Project Overview

This project demonstrates the concepts of Sampling and Aliasing using MATLAB. It helps visualize how sampling frequency affects the representation and reconstruction of a signal.
